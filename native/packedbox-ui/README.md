# packedbox-ui

Thin **GTK4 + libadwaita** UI over the packedbox elomaxz core (Phase 4).

Stub binary only. Prefer GTK4/libadwaita per [ADR-0001](../../docs/ADR-0001-tech-stack.md).

## Dependencies (Phase 4)

- libadwaita-1

## Build

```bash
cmake -B build -S .
cmake --build build
```
